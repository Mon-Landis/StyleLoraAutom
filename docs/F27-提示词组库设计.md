# F27 提示词组库设计

本文为模块实现规格草案；只新增设计，不实施代码或变更其它文档。
权威顺序：本次用户需求 > 已有决议 > 本文建议；Q 项未经裁决不视为已定。
依据：F06/F07 §3–4、docs/05 §4.4、types.py、dictionaries.py、exchange.py、U8。
范围外文件未用于推断现有 API 路由；第 8 章是 `/api` 风格草案。

## 1 定位与范围

产品的提示词生产分为「特征组库」和「提示词组库」。
特征组库承载角色、动作、构图等标准 tag 原料；本期仅规划，不实现。
提示词组库保存场景、人物、动作、构图等完整内容，排除画风段。
组内每条内容应提供一张图的基本信息；结构有效不代表语义完整。
U8 的默认类别继续为 `full_content`，界面名称「完整内容提示词」。
`kind=prompts` 与类别、scope 分离；其它类别和自动格式化替换只预留。
继承 F06/F07 的不可变 DTO、导入预览、任务快照、revision CAS、原子写。
替换旧 prompts 条目的表达方式，新增双自然语言、禁用、预览图和作用范围。
旧特征字典及抽样算法本期不重构；旧任务通过明确适配器读取新组。
组库过滤不替代已有生成侧 rating 围栏，也不自动改变端点的内容能力。
本文推荐参数和行为列入 C/Q；用户明确要求的行为无需再次审批。

## 2 数据模型

持久化 prompts 升为 `schema_version=3`；features 保持现状。
交换格式另用 `format_version=1`，不得把交换版本当作存储版本。
类型别名：`Scope=Literal['global','project']`，`Aspect=Literal['landscape','portrait','square']`。
`RenderMode=Literal['tags_plus_nl','full_nl']`；ID 为校验后的 UUID 字符串。
`GroupRef={scope:Scope, project_token:str|null, group_id:str}` 是运行时限定引用。
project_token 由已打开项目上下文产生，不作为绝对路径写进组文件。
下列模块名均为职责划分建议，不要求对应同名新文件。

### 2.1 字段合同

| 对象 | 字段：类型 | 规则 |
|---|---|---|
| Group | dictionary_id:str；name:str | 沿用字典 ID；名称去首尾空白，1–128 字符 |
| Group | schema_version:int；kind:str；category:str | 固定 3 / prompts / full_content |
| Group | revision:int；scope:Scope；nsfw:bool | revision 从 1 起；scope 必须匹配存储根 |
| Group | entries:tuple[Entry,...] | 可空；导入新组要求至少一条有效输入 |
| Group | _operations:Mapping[str,OperationReceipt] | 内部幂等凭据，禁止导出 |
| Entry | entry_id:str | 组内唯一 UUID，编辑不变 |
| Entry | tag:tuple[str,...] | 默认空；标准 tag，不含画风串 |
| Entry | expand_nl:str | 默认空；追加在 tag 后的自然语言 |
| Entry | nl:str | 默认空；独立描述 tag 核心内容的完整自然语言 |
| Entry | disable:bool | 默认 false；禁用仍持久保存及导出 |
| Entry | aspect:Aspect|null | 空时沿用生成源默认图幅 |
| Entry | preview:PreviewRef|null | 每条最多一张逻辑预览图 |
| Entry | completion:CompletionState | 内部任务状态，不属于 AI 内容合同 |
| PreviewRef | asset_revision:str；sha256:str | 不可变资源版本与内容摘要 |
| PreviewRef | width:int；height:int；mime:str | 存处理后的尺寸，mime 固定 image/webp |
| CompletionState | state:str；missing:tuple[str,...] | 状态见第 6 章；missing 仅 tag/expand_nl/nl |
| CompletionState | task_id:str|null；error_code:str|null | 错误不携带端点、凭据或完整模型输出 |
| OperationReceipt | digest:str；result:JsonObject | 请求摘要与可重放结果，同组文件原子保存 |

模型模块负责验证、规范化及旧类型适配，依赖现有 PromptError/Issue 和可信 tag 映射。
公开接口：`validate_entry(raw:JsonObject)->EntryDraft`；`migrate_v2(raw:JsonObject)->Group`。
`EntryDraft` 为内容字段加可选 entry_id/aspect；验证失败返回逐字段 Issue。
幂等性：相同输入得到相同规范内容；新 ID 在导入预览时生成并冻结，不在重试时再生成。
最小测试：空白全空拒绝、disable 类型拒绝字符串、同一迁移重试 ID 不漂移。

### 2.2 v2 迁移

原 `dictionary_id/name/category/revision` 保留；tags→tag，natural_language→expand_nl。
nl 初始化空，disable=false，aspect 保留；scope=global，preview=null。
条目 ID 推荐 UUIDv5(组 ID, 原条目序号)，迁移时固定，后续重排不重算。
任一旧 rating 为 questionable/explicit 时推荐整组 nsfw=true，保守提升并出报告（Q08）。
旧 rating 保存在迁移备份，不把 rating 静默等同新条目字段；空评级不证明安全。
先写原始文件备份并校验，再经 CAS 提交 v3；迁移计一次 revision 增量。
旧条目缺 nl 标待补全，但不自动调用 LLM；仍按可用字段抽取（Q05）。
v1 通过现有解码合同归一到 v2 后迁移；高于 v3 拒绝，禁止猜测字段。
迁移收据写进 _operations；重复启动识别 v3，不重复迁移或新建备份。
旧客户端不能写 v3；兼容适配器输出 tags/natural_language/aspect/rating，rating 不伪造。
旧 DTO 无法无损表达 nl/disable/preview，禁止经旧保存入口回写新组。

## 3 存储

本次用户新决议覆盖 docs/05「项目不存字典内容」对提示词组的限制。
仍保持 source_items 只存提示词本体、不新增字典溯源字段，不引入 project.db 字典表。
产品根 P=`%APPDATA%/StyleLoraAutom`；项目根 J 为已打开项目目录。
产品组文件：`P/dictionaries/prompts/<group_id>.json`。
项目组文件推荐：`J/dictionaries/prompts/<group_id>.json`（C40）。
两层图目录均为各自根下 `dictionaries/prompts/previews/<group_id>/<asset_revision>/`。
图目录内 `<entry_id>.webp` 与 `<entry_id>.thumb.webp`，以条目 ID 命名。
资源版本子目录支持先发布图、后原子切换组 JSON，避免多文件假原子性。
选择文件而非 DB：复用现有 CAS/备份/交换模块，项目复制可带走完整组。
文件缺点是跨组事务需恢复协议；本期 scope 不允许原地切换，见 Q09。
创建、导入默认 scope：未开项目 global，已开项目 project；用户选择优先。
project 目标在提交时必须仍是预览时的项目 token，不能随当前项目变化。
关闭项目立即移除其列表和新抽取资格，拒绝后续项目写入，暂停未提交补全任务。
迁移项目时一并移动 dictionaries 目录；相对引用不变，无外部绝对路径。
复制项目保留组 ID；两个项目上下文相互隔离，全局同 ID 也不覆盖。
全局组不随项目复制；已物化 source_items 不因组丢失而失效。

### 3.1 仓储与图像模块

仓储职责：限定根解析、读写、CAS、操作凭据、迁移、删除墓碑与孤儿清理。
接口：`load(ref:GroupRef)->Group`；`save(ref:GroupRef,value:Group,expected_revision:int,request_key:str)->int`。
接口：`delete(ref:GroupRef,expected_revision:int,request_key:str)->DeleteReceipt`。
依赖：现有 dictionaries 的锁、digest、同目录临时文件→flush/fsync→replace 写入方式。
读取逐个隔离损坏组，报告 storage:corrupt_snapshot；写错映射 storage:io_error，不覆盖旧文件。
幂等：先核对 request_key 摘要，再检查 CAS；同键异载荷冲突，相同返回首次结果。
删除先把组原子发布为内部墓碑，列表排除；墓碑保留操作凭据，资源异步清理。
最小测试：旧 revision 拒绝、断电只见旧/新完整 JSON、删除重试返回同一收据。
图像模块职责：解码检查、去元数据、缩放、缩略图、资源发布及按策略提供图像。
接口：`prepare_preview(data:bytes,entry_id:str)->PreparedAsset`；`publish(asset:PreparedAsset,ref:GroupRef)->PreviewRef`。
依赖本地图像编解码器和仓储；禁止远程 URL 下载及 SVG/动画输入。
建议输入限 10 MiB、解码限 40 MP；输出长边≤2048px，缩略图长边≤320px（Q10）。
保持比例，不放大小图；PNG/JPEG/WebP 静态图转 WebP，移除 EXIF。
错误 image:invalid/image:too_large；资源失败时整次带图修改不提交。
幂等：资源摘要相同可复用；换图生成新 asset_revision，不覆写仍被旧 JSON 引用的资源。
最小测试：畸形图拒绝、缩略图尺寸正确、提交前崩溃只遗留可清理孤儿。
导入/换图顺序：隔离暂存→校验全部资源→发布不可变资源→CAS 替换组文件。
CAS 或 IO 失败保留原组；孤儿按未引用且过保留期回收，不能删除活跃暂存目录。
原图缺失时显示占位图和告警，保留文本条目；读取不得改写组 revision。

## 4 NSFW 全局开关与图像表现状态机

产品设置 `nsfw_enabled:bool=false`；并列 `image_display:click_reveal|hover|show`。
图像模式默认推荐 click_reveal（Q01），产品设置持久化，修改经设置 revision CAS。
`revealed_this_run:bool=false` 仅由后端当前程序进程持有，不进配置/磁盘/localStorage。
多个窗口共享此状态；页面刷新不重置，程序退出后重置。
敏感图谓词 S：提示词组 nsfw=true，或数据集 rating∈{questionable,explicit}（Q02）。
组未标 nsfw 但图另有可信敏感评级时也取 S=true；未评级不自动宣称安全。
组可见性与图像清晰度分开：关 NSFW 时整组及其生成源选项不可见。
后端列表、搜索、计数、直接内容读取及新抽取统一过滤，不能只在前端隐藏。
数据集工作台图片仍占原位置，S 图应用同一状态机，避免改变数据集记录（Q02）。

| S | NSFW 开关 | 模式/会话 | 显示 | 聚焦与操作 |
|---|---|---|---|---|
| false | 任意 | 任意 | 清晰 | 无 NSFW 提示 |
| true | 关 | 任意 | 模糊 | 聚焦提示「nsfw 屏蔽」，无显示按钮 |
| true | 开 | click_reveal 且未确认 | 模糊 | 聚焦提示「nsfw 内容」，额外「显示」按钮 |
| true | 开 | click_reveal 且已确认 | 清晰 | 保留 nsfw 标记 |
| true | 开 | hover | 默认模糊 | 鼠标悬停/键盘聚焦清晰，离开恢复 |
| true | 开 | show | 清晰 | 保留 nsfw 标记 |

点击「显示」将 revealed_this_run=true，本次运行内 click_reveal 对所有敏感图放行。
hover/show 本身不隐式设置会话确认；确认不改变 hover 离焦恢复的模式语义（Q01）。
关闭开关立即重新模糊并隐藏敏感组；推荐保留内存确认，再开启时按原状态显示（Q01）。
切换模式立即重算，不把当前清晰状态写成条目属性；触屏 hover 用聚焦/失焦替代。
界面同时提供键盘可访问的提示与确认；NSFW 标识不依赖颜色表达。
策略模块职责：持有设置快照、会话状态、可见性与图像显示决策，依赖产品设置服务。
接口：`can_select(group:Group,settings:SafetySettings)->bool`。
接口：`image_policy(sensitive:bool,focused:bool,settings:SafetySettings,revealed:bool)->ImageDecision`。
接口：`confirm_reveal()->SessionSafetyState`；`ImageDecision={blur:bool,hint:str|null,can_reveal:bool}`。
错误：关闭模式时 confirm_reveal 返回 safety:disabled；设置 CAS 冲突要求重读。
幂等：重复确认仅返回 true；纯策略函数相同输入相同输出。
最小测试：状态表每行、窗口共享、退出重置、关开关覆盖历史确认、两工作台一致。
模糊是表现规则，不宣称权限隔离；预览缓存键必须含当前策略版本，避免旧清晰图闪现。

## 5 导入导出标准与校验

保留 JSON 运行存储；无需数据库导入。新交换标准为 JSON 与文件夹/zip 组包。
JSON 模式仅传文本内容和元数据，不复制、下载或恢复任何预览图。
组包可携带预览图；两类入口共用规范化、逐行验证、预览和提交管线。

### 5.1 JSON Schema 合同

下列为 Draft 2020-12 条目 schema；先去首尾空白，再校验非空与长度。
```json
{"type":"object","additionalProperties":false,
 "properties":{
  "tag":{"type":"array","maxItems":256,"items":{"type":"string","minLength":1,"maxLength":256}},
  "expand_nl":{"type":"string","maxLength":16000},
  "nl":{"type":"string","maxLength":16000},
  "disable":{"type":"boolean","default":false},
  "aspect":{"enum":["landscape","portrait","square",null]}},
 "anyOf":[
  {"required":["tag"],"properties":{"tag":{"minItems":1}}},
  {"required":["expand_nl"],"properties":{"expand_nl":{"minLength":1}}},
  {"required":["nl"],"properties":{"nl":{"minLength":1}}}]}
```
缺字段归一为 tag=[]、expand_nl=""、nl=""、disable=false；null 不等于空字符串。
aspect 为可选扩展（Q04）；其余三个内容字段至少一个非空，最多缺两个。
组导入根 schema：`oneOf=[Entry[], {group_metadata?:Metadata,prompts:Entry[]}]`。
条目导入根 schema：`oneOf=[Entry[],Entry]`，目标组必须已明确。
数组输入要求 minItems=1；有效行数量在逐行验证后必须≥1。
组对象 required=[prompts]、additionalProperties=false；canonical 键仅 prompts。
promprt 作为笔误拒绝并提示正确键名；prompt 别名是否兼容列 Q03。
Metadata 全字段可选：`format_version:1, group_id:UUID, name:str, nsfw:bool, scope:Scope, category:'full_content'`。
Metadata additionalProperties=false；未知高版本拒绝，空 metadata 合法。
选源后展示 ID、名字、安全分级、scope 表单，源字段优先填入，用户可修改。
缺省 ID 生成 UUID；名字「导入提示词组」；安全默认非 NSFW并提示核对；scope 按项目状态。
源指定 project 而未开项目时保留选择并阻止提交，提示打开项目或改选 global。
同 scope/项目内 ID 冲突推荐默认生成新 ID；追加已有组必须显式选目标，不隐式覆盖（Q07）。
改 metadata、来源格式或目标后重新生成预览摘要，不得沿用旧 preview_id。
部分行无效时跳过，报告原行号/字段/原因；提交按钮显示有效/跳过数（Q06）。
全部无效、缺 prompts、根类型错误均阻止导入并给可操作的前端提示。
JSON 导出包含禁用条目和空字段，不含 preview/completion/_operations；单条复制遵循同一合同。

### 5.2 组包与安全边界

标准根为 `group.json` + `previews/`，zip 根同结构，不自动猜嵌套顶层目录。
group.json 使用 `{group_metadata, prompts, preview_manifest}`；扩展仅组包入口允许。
包条目采用 Entry 内容字段加 `entry_id:UUID`；manifest 按 entry_id 关联图像。
manifest 值为 `{file:'previews/<entry_id>.webp',sha256:str}`；缩略图本地重建不必携带。
文件夹与 zip 都校验真实路径、摘要和图像解码，不信任扩展名或源文件元数据。
zip 自动解压到隔离临时目录，拒绝绝对路径、盘符、UNC、..、NUL、符号链接和重解析点。
规范化后重复路径、Windows 大小写冲突、保留名、NTFS ADS、额外未声明文件均拒绝。
推荐上限：JSON 10 MiB、10,000 条；zip 100 MiB、解压总量 200 MiB、10,001 文件（Q10）。
流式累计实际解压字节；单图仍限 10 MiB，压缩比>100:1 拒绝，不只信 ZIP 目录声明。
解析 UTF-8，可接受 BOM；重复 JSON 键、NaN、Infinity 拒绝，不自动猜本地编码。
组包图缺失/摘要不符默认阻止提交；用户可明确改为纯 JSON 重新预览以保留文本。
单包只表示一组；多组 LLM 输出由任务适配器拆成多个独立预览，不扩展根为含糊数组。
导出冻结一次组 revision，图引用同一版本；导出结束前保留资源读取租约。

### 5.3 交换模块与错误码

交换模块职责：解析格式、来源转换、限额校验、报告、冻结预览与原子提交。
接口：`preview_import(data:ImportSource,options:ImportOptions)->ImportPreviewV3`。
接口：`commit_import(preview_id:str,digest:str,expected_revision:int,request_key:str)->ImportResult`。
接口：`export_group(ref:GroupRef,format:Literal['json','folder','zip'])->ExportArtifact`。
ImportSource=JSON 字节/已授权文件夹句柄/zip 字节；ImportOptions 含 metadata 覆盖与 source_format。
ImportPreviewV3 含有效条目、跳过行、转换警告、图映射、目标 token、base_revision、digest。
依赖模型、仓储、图像模块及 F28；预览仅写隔离暂存，提交才使组可见。
来源选 nai 时，入库前逐条转换；文本接口固定 `convert_nai_to_anima(text)->(text,warnings)`。
适配器把 tag 按 F28 文本合同交给转换器并解析回数组；expand_nl/nl 的转换范围由 F28 定义。
转换后必须通过本条目 schema，最终内容为 Anima 规范；不得自行设计替代转换协议。
转换失败的行列入无效报告；所有 warnings 在预览可见；普通来源不调用转换器。
幂等：同预览摘要与请求键只提交一次，图像发布失败不得留下半个可见组。
最小测试：有效/无效混合、全部无效、重复提交、转换失败、zip 越界与断流。

| 错误码 | HTTP 建议 | 前端处理 |
|---|---|---|
| schema:invalid / import:empty | 422 | 定位字段或提示至少一条有效条目 |
| import:encoding / newer_version | 422 | 提示 UTF-8 / 升级应用 |
| import:unsafe_archive / import:limit | 422 / 413 | 拒绝整包，不开始提交 |
| dictionary:revision_conflict | 412 | 重读并重新预览，不静默重试覆盖 |
| dictionary:request_key_conflict / group:id_conflict | 409 | 更换请求键 / 选择冲突处理 |
| project:closed / completion:stale | 409 | 重开原项目 / 复核补全结果 |
| dictionary:not_found / safety:hidden | 404 | 移除失效选择，不泄露隐藏组内容 |
| storage:io_error / storage:corrupt_snapshot | 500 | 保留旧数据，提示重试或恢复备份 |
| preview:expired / image:invalid / image:too_large | 410 / 422 / 413 | 重新预览 / 更换图像 |

## 6 缺口推导与 LLM 补全任务

缺失定义：规范化后 tag=[] 或自然语言为空；aspect 不计入三字段缺口。
只有 expand_nl 时先确定性设置 nl=expand_nl，只把 tag 交给 LLM 推导。
其它组合的缺字段全量交给 LLM 推理，不用 tag 拼接假冒完整 nl。
三个字段均非空不进自动补全队列；用户可以编辑，但「补全缺失」为无操作。
有缺字段的有效条目标记 pending（待补全），导入成功后才可创建任务。
推荐导入预览提供「提交后补全」选项，默认不调用付费服务（Q05）。
禁用条目也标缺口，但默认批量任务跳过；单条右键可显式补全，disable 不改变。
状态：pending→queued→running→complete；异常→failed；取消/退出→paused 或 canceled。
失败保存原始有效内容及错误码，显示「补全失败，可重试」，不把条目判成无效。
任务输入冻结 GroupRef、entry_id、内容摘要、缺字段集合及目标组 revision。
调用新 skill `skills/nai-prompt-generator/`；该 skill 由另一 agent 编写，本文不创建或改写。
适配其条目输出为 tag/expand_nl/nl/disable；可一次返回多组，但必须有明确组与条目映射。
不依赖模型自行保留 ID；任务包装层维持批次映射，数量/顺序不匹配时拒绝自动写回。
模型只能填任务声明的空字段，已有字段与 disable 保留，模型额外修改作为警告。
返回仍有缺口时保留已验证的新增字段，状态 failed，错误 completion:incomplete。
写回先检查内容摘要；条目被编辑或删除时标 stale，不覆盖人工变更。
仅无关条目改变 revision 时，可重新读取并在锁内复核摘要后以新 revision CAS 合并。
模型调用超时/未知结果不自动重放；已提交结果保留，显式重试生成新 attempt。
补全模块接口：`enqueue(ref:GroupRef,entry_ids:tuple[str,...],request_key:str)->TaskView`。
接口：`apply_result(task_id:str,result:CompletionBatch,request_key:str)->CompletionReport`。
依赖统一任务调度和 LLM 调度接口；沿用 U10 的取消与进程退出恢复语义。
幂等：任务键+输入摘要去重，结果按 task_id/entry_id/attempt 记收据，重复回调不重复追加。
错误 completion:unavailable/stale/incomplete；skill 未就绪时不提交调用，条目保持 pending。
最小测试：仅 expand_nl、其余六种非全空组合、人工并发编辑、重复回调、取消后恢复。

## 7 抽取规则

顺序：解析限定组引用→检查项目与 NSFW→排除 disable→有效性→渲染→抽样/冻结。
关闭 NSFW 时提示词源列表不列敏感组；旧请求直接引用隐藏组也拒绝。
推荐 pending/failed 不阻止抽取，只要选定模式能得到非空内容，并附回退警告（Q05）。
`tags_plus_nl`：tag 用 `, ` 连接，再追加 expand_nl；两者皆空时回退 nl。
`full_nl`：优先 nl；为空时回退 tags_plus_nl，返回 render:fallback 警告（Q05）。
禁止两个模式相互递归回退；三者皆空视为损坏条目并排除，报告错误。
RenderResult 含 `text:str, requested_mode:RenderMode, effective_mode:RenderMode, warnings:tuple[Issue,...]`。
前端显示模式与生成 render_mode 独立；改变列表显示不能更改已配置生成源。
源配置锁定 render_mode，冻结后的 source_items 只有实际文本和既有 aspect 等字段。
aspect 有值优先条目值，否则用源默认；画风段由既有生成链另行添加。
同条 tag 去重保序；跨条重复键为规范 tag 集合+expand_nl+nl+aspect，不含 disable。
相同内容但 disable 不同只报冲突，不擅自启用旧条目；不同 NL/aspect 可分别保存。
同批相同非空 tag 集合最多抽一条，继承旧抽样约束；纯 NL 用规范渲染文本去重。
可用量不足返回可用数/缺额，不自动抽取禁用或敏感条目凑数。
关闭 NSFW 时运行任务推荐继续执行已物化内容，但停止新抽取，图像立即模糊（Q11）。
运行任务重新启动时仍须过当前策略；项目关闭遵循既有任务暂停规则，不改写已存文本。
渲染模块职责：过滤、双模式渲染、兼容旧抽样投影；依赖策略模块和现有抽样器。
接口：`render(entry:Entry,mode:RenderMode)->RenderResult`。
接口：`freeze(refs:tuple[GroupRef,...],mode:RenderMode,seed:int,count:int)->FrozenSeeds`。
错误：source:insufficient、safety:hidden、project:closed；警告与致命错误分开返回。
幂等：相同冻结快照、seed、算法版本得到相同结果；重放使用快照，不重新读可变组。
最小测试：禁用排除、敏感组排除、双向回退、纯 NL 去重、同 seed 可重放。

## 8 API 草案

以下为 `/api` 路由草案；接入时复用现有路由注册和错误序列化器，不宣称已存在。
API 模块负责 DTO、限定引用、策略检查与 HTTP 映射；依赖仓储、交换、图像、任务和设置服务。
公开类型：`Page[T]={items:list[T],next_cursor:str|null}`；`ErrorBody={error:{code:str,message:str,details:JsonObject}}`。
错误体须由现有统一封装输出；上述字段为所需语义，实际字段兼容现有合同，不另造第二套错误体。
下表 `G=/api/prompt-groups/{group_id}`、`E=G/entries/{entry_id}`；请求同时携带 GroupRef 的 scope/project_token。
组创建在 body 给 scope/project_token；其它组路由用 query；project_token 不接受文件系统路径。
分页 `limit:int=50`，建议范围 1–200；`cursor:str|null` 为不透明 keyset，不接受 offset。
组按 dictionary_id、条目按 entry_id 稳定排序；游标绑定过滤条件、项目、策略版本，条目游标还绑定组 revision。
策略、过滤或 revision 改变返回 409 `pagination:stale`；非法游标返回 422 `pagination:invalid`，均从首页重读。
响应 revision 对应强 ETag；既有资源修改须 `If-Match`，缺失 428 `revision:required`，不匹配 412 `dictionary:revision_conflict`。
创建新资源用 `If-None-Match: *`；条目增删改均以所属组 ETag 做 CAS，成功返回新组 ETag。
所有写入携带 `Idempotency-Key:str`；同键同摘要重放首次结果，异摘要 409 `dictionary:request_key_conflict`。
重放前仍检查项目与当前可见性，避免凭旧收据读取隐藏内容；业务 CAS 在收据查找后处理。
通用错误：422 `schema:invalid`、404 `dictionary:not_found`/`safety:hidden`、409 `project:closed`、500 `storage:io_error`。
NSFW 关闭时先服务端过滤再分页/计数；直接读取、导出、图像和任务入口同样检查，隐藏组统一 404。

API 最小测试：缺 CAS 拒绝、重复创建、跨项目游标拒绝、隐藏组计数不泄漏、图像策略检查先于 304。

## 11 边界问题讨论

1. 同组 tag 重复？→条内规范化去重保序；跨条按 §7 比较，NL/aspect 不同保留，抽样遵守同 tag 集合约束。
2. 超长条目？→按 §5 字符数与条数上限逐字段报错，不截断后静默保存；请求体超限直接 413。
3. id 冲突？→新组预览生成新 ID 并显示映射；追加必须显式选目标，重试沿用冻结 ID（Q07）。
4. 项目组与全局组同名？→允许同名，以 scope、项目上下文和 ID 区分，禁止仅凭名称合并。
5. 关闭 NSFW 时任务已引用敏感组？→推荐已物化任务继续，停止新抽取并立即重算图像状态（Q11）。
6. 导入中途失败是否部分可见？→确认后的有效集合单组原子提交；资源或 CAS 失败保留旧组，暂存异步清理。
7. 预览图缺失？→已有条目占位并告警；导入组包缺图阻止确认，可显式转纯 JSON 重新预览。
8. 禁用条目是否导出？→完整导出并保留 disable=true；抽样和默认批量补全排除，不能导出时丢失用户数据。
9. zip 炸弹/zip slip？→按实际解压量、压缩比和路径白名单限制；目录、链接与重解析点全部检查，整包失败。
10. 非 UTF-8 编码？→接受 UTF-8/BOM，其余明确报 import:encoding；提供重存编码提示，不猜测乱码。
11. nsfw 组内条目是否单独标记？→本期无条目 nsfw 字段，继承组属性；可信图像评级仍参与 §4 敏感谓词。
12. scope 切换是否移动组？→本期禁止原地改 scope；用导出→目标导入→人工删除旧组，非跨根原子移动（Q09）。
13. 项目目录复制/迁移后项目组？→随相对目录带走，保留组 ID，打开后分配当前 project_token，旧 token 失效。
14. 预览后切换项目或编辑条目？→确认校验冻结 token/revision；失败重新预览，不能写入当前另一个项目。
15. 导出期间换图或删除组？→持有冻结 revision 的资源租约，产物一致；结束后释放，清理器避开租约。
16. 设置开关与分页请求并发？→策略版本变化使旧游标失效；前端忽略旧响应，服务端再次按当前策略过滤。

## 12 测试清单

T01 数据模型：三内容字段全空拒绝；仅一项有效接受并标记缺口。
T02 数据模型：disable 字符串、非法 aspect、未知字段返回逐字段 Issue。
T03 迁移：v2 字段映射正确，重复启动不改 ID、不重复备份、不重复提升 revision。
T04 仓储：旧 If-Match 返回 412，缺失返回 428，原组及图引用不变。
T05 仓储：同键同摘要返回首次结果；同键异摘要 409，不发生第二次写入。
T06 仓储：发布图后或替换 JSON 前中断，仅见完整旧组或新组，孤儿可回收。
T07 删除：非空组/条目删除重试复用墓碑收据，资源清理不影响活跃租约。
T08 分页：默认 50，静态数据 keyset 无重复遗漏，非法和跨过滤游标被拒绝。
