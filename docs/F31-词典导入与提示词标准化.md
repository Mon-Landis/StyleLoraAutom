## 2. 公共类型与 HTTP 合同

```typescript
type Scope = 'global' | 'project';
type GroupRef = {scope: Scope; project_token: string | null; group_id: string};
type PromptFormat = 'nai' | 'anima';
type EntryDraftV5 = {nl: string; variants?: Record<string,string>; disable?: boolean;
  aspect?: 'landscape' | 'portrait' | 'square' | null};
type EntryPatchV5 = Omit<Partial<EntryDraftV5>, 'variants'> &
  {variants?: Record<string,string | null>; source_format?: PromptFormat};
type ImportFormat = 'json' | 'txt' | 'zip' | 'folder' | 'nai_images' | 'nai_image_zip';
type ImportOptions = {format: ImportFormat; level: 'group' | 'entries'; ref?: GroupRef;
  source_format?: PromptFormat; metadata?: {name?: string; scope?: Scope; nsfw?: boolean}};
type ImportIssue = {code: string; row?: number; field?: string; file_index?: number; message?: string};
type ImportResult = {ref: GroupRef; inserted: number; duplicates: number;
  conflicts: ImportIssue[]; revision: number; version: string};
```

`G=/api/prompt-groups/{group_id}`，`E=G/entries/{entry_id}`；G/E query 携带 scope/project_token。
写请求使用 `Idempotency-Key`（1..256 字符），修改带 `If-Match: "revision"`，新组确认带 `If-None-Match: *`。
通用错误：422 `schema:invalid/newer_version/import:empty`；413 `import:limit/image:too_large`；404 `dictionary:not_found/entry:not_found`。
并发错误：428 `revision:required`；412 `dictionary:revision_conflict`；409 `dictionary:request_key_conflict/project:closed/group:id_conflict`。
预览错误：410 `preview:expired`；422 `import:unsafe_archive/image:invalid`；500 `storage:io_error/storage:corrupt_snapshot`。
预览返回 200；确认返回 200 ImportResult 和 ETag；字段错误用现有 Issue 封装，新增码需接入统一 HTTP 映射。
同键同请求先重放收据再检查 CAS；不同请求摘要返回 409。摘要包含文件顺序、内容哈希、选项、转换版本。

### 4.1 PNG 元数据解析合同

先验 PNG 签名、chunk 长度/边界/CRC、IEND；未知附属块跳过，私有 Takoma 不解析、不存储。
tEXt：keyword NUL 后按 Latin-1 文本读取；Comment JSON 接受标准 JSON Unicode 转义。
iTXt：逐项读取 keyword NUL、compflag、method、language NUL、translated NUL、UTF-8 text。
compflag 仅 0/1，method 仅 0；flag=1 时限量 zlib 解压，不能把 language/translated 算进正文。
zTXt：keyword NUL、method=0、zlib 压缩的 Latin-1 text；截断或非法压缩报告 `metadata:invalid`。
同名候选按文件顺序尝试，取第一个结构合法且有非空正面内容者；无效候选记 warning 后继续低优先级。
顺序固定：Comment JSON v4_prompt → Comment.prompt → Description → A1111 parameters 正面段 → alpha 隐写。
v4 读取 `v4_prompt.caption.base_caption:str` 与 `char_captions[].char_caption:str`；类型不匹配该候选无效。
空字符提示词用 strip 判定并跳过，保留非空值原始空白；拼接为 `base + ''.join('\n\n'+c for c in characters)`。
base 为空但存在角色仍可导入；无角色不追加分隔符。用 strip 判最终空值，但不以 strip 的结果替换原文。
Comment.prompt 与 base 相等时不能重复追加；不读取负向 v4_negative_prompt/uc，不拼角色坐标。
A1111 parameters 截取开头至独立行 `Negative prompt:` 或参数尾行 `Steps: <数字>, ...` 之前；不靠任意正文中出现的同名词截断。
alpha 兜底仅在上述来源没有有效内容时运行：Pillow RGBA 原始 alpha LSB，按 x 外层/y 内层、字节 MSB 优先读取。
先识别 15 字节 `stealth_pngcomp`/`stealth_pnginfo`，再读 32 位大端 payload 位长度；长度须整字节且不超可用像素。
comp payload 用有上限的 gzip 解压；info 为未压缩 UTF-8 JSON（测试覆盖两种），复用同一正面字段提取器。
隐写 JSON 若含字符串 Comment 则严格解码一次；不递归猜测任意包装。无 alpha 不尝试伪造透明通道。
限制：每图 10 MiB、40M 像素；整批 100 MiB/最多 1000 图；元数据单块压缩输入 1 MiB、解压输出 2 MiB、累计 4 MiB。
PNG 普通 IDAT 等块仍受单文件上限；不得套用 1 MiB 文本限制拒绝合法 IDAT。逐块读取并检查剩余字节后才分配。
zlib/gzip 解压流到上限立即停止；拒绝尾随压缩流及截断流；禁止先无限解压再检查长度。
提取仅返回正面文本、来源、受限诊断；不记录 signed_hash，也不在日志、异常、SSE 中输出完整元数据。

### 6.1 标准化语义

新增纯模块 prompts/prompt_normalize.py；复用 anima_convert/nai_convert 的扫描、解析、Decimal 和 span 类型。
来源 anima：调用 convert_anima_to_nai，复用既定逆倍率；给转换器增加可选正文空格输出模式，旧工具默认行为不变。
来源 nai：直接解析 NAI 语义，不走 nai→anima→nai；`{}` 每层 ×1.05，`[]` 每层 ÷1.05，显式数值乘算。
规范权重输出为 `w::片段::`，权重 1 省略包装；保留正、零、负有限权重，入库不做 Anima 专属删除/钳制。
采用 Decimal precision=128；NAI 规范权重量化至小数 8 位、HALF_UP、去尾零；舍入有变化给 normalization:rounded 警告。
Anima 来源沿用已有转换精度和损失警告，不宣称比旧转换器更高精度。资源上限不借数值钳制绕开。
画师规范为 `artist:名称`，Anima 的 @ 仅在语法词项前缀位置转换；不把句中邮件地址视为画师。
正文 `_`→空格；NAI 字面转义由词法器解码/序列化一次，逗号及括号不以全串正则处理。
必须保留原有换行数量、前后空白、重复项及顺序；CRLF/CR 统一 LF。权重包装替换采用源 span，不用 join(', ') 重排整个 nl。
自然语言保持原文除下划线和行结束规范化；现有 `_line_blocks` 的启发式不能跳过句中明确权重/画师语法。
扫描显式方言语法并保留其余源片段；字面控制符须转义。混合来源不自动猜测，用户选择来源后预览转换结果。
非法/不闭合权重结构不能静默修补入库：422 `normalization:syntax`；深度/数值长度/字符限额为 413 `import:limit`。
所有恢复型转换警告由标准化入口分类：结构错误阻止该条，正常精度损失为 warning；禁止空结果当成功。
目标不变量：`normalize(normalize(x,'nai').text,'nai').text` 不变；读取 v5 只验证，不重新执行源方言转换。
旧无版本输入默认 anima 并在预览标明；新交换 v2 prompt_format 必须 nai，来源覆盖冲突返回 422 schema:invalid。
手工默认 nai；来源选择、图片固定 nai、旧导入默认 anima 三者必须在 UI 中明确区分。

### 6.2 推送端点边界与测试

### 7.1 v5 数据合同和旧数据迁移

Entry 保留 entry_id/nl/variants/disable/aspect/preview/completion/generated/pending/edit_versions，移除 tag/expand_nl。
BaseField=Literal['nl']；GeneratedFields={nl:bool,variants:Mapping[str,bool]}；FieldVersions={nl:int,variants:Mapping[str,int]}。
pending 仅允许 nl，PendingField 结构沿用 F30；completion.missing 仅允许 nl；有效 Entry 必须 nl.strip() 非空。
新建 nl 最大 16000 字符；variants 继续最多 64 个 key、每值 16000，key 规则沿用 F30。
旧迁移合并可能超过 16000：不得截断。超过新限制则阻止该组迁移，报告 entry_id/长度，保留原文件，供用户导出后拆条修复。
`migrate_v4(raw:JsonObject)->Group`：按旧 tag 顺序用 ', ' 连接，取非空的 `[tag_text,expand_nl,nl]`，以 '\n\n' 拼接。
判空用 strip，拼接使用原值；即使 expand_nl 与 nl 一致也保留两段，不猜测语义重复。预览/迁移报告提示可能重复。
合并内容按旧库 anima 语义标准化；variants 也从旧 anima 适配。历史误标来源不能可靠识别，备份后人工修正，不启发式猜权重。
v1/v2 先适配 tags/natural_language；v3 补 v4 结构，再直接生成 v5；一次持久迁移只增加一次 revision。
保留 UUID、scope、NSFW、aspect、preview、variants、auto_complete、_operations；不迁移 features 或 project.db。
generated.nl 仅当所有参与合并的非空源字段均标 generated=true 时为 true；含人工段则 false。variants 标记逐 key 保留。
edit_versions.nl 取旧三字段最大值+1；variants 计数保留。迁移清除所有旧 pending，completion 变 complete/missing=()。
仓储锁内读取原字节→纯迁移及全量校验→写并校验 `.v<源版本>.bak`→原子替换→记录 migration:v5 收据。
复用 `_migration_backup`（group_store.py:26）；失败不覆盖原件，不覆盖不同内容备份。高版本拒绝，墓碑只升级外壳不解码 Entry。
重复读取 v5 不备份、不升 revision；保留迁移报告/原始备份，恢复需停止写入并整组回退，不能只回退 schema 数字。
备份是旧字段原始内容保留位置；v5 正式内容不再暗藏 tag/expand_nl，也不把它们伪装成 variants。
`dictionaries.py` 只读兼容映射为 tags=()、natural_language=nl；validation 版本白名单同步 v5，禁止旧入口覆写新组。
render 统一输出 nl；旧 tags_plus_nl/full_nl 请求值暂适配为同一 nl 并给弃用警告；抽样按规范文本去重，不再依赖 tag 集合。

### 7.2 交换兼容与 API

新交换 format_version=2，TXT 头升级 `# stylelora-prompts-txt v2`；不混淆组存储 schema_version=5。
兼容 JSON/包 v1、TXT v1/无头旧文本；先旧字段映射再归一化。版本不明的裸对象按字段形状走显式旧适配并展示警告。
v2 不接受 tag/expand_nl；内部 generated/pending 等仍拒绝。TXT 保持一物理行一个 JSON、BOM/CRLF 支持及原物理行诊断。
GET G/entries、GET E 输出 v5；POST/PATCH E 提交废弃字段为 422 schema:invalid，不能悄悄丢弃；旧格式只允许交换适配入口。
前端类型变为 PromptView='prompt'|'variants'；本地旧 default/nl 值映射 prompt；显示/编辑都使用 nl 原文本，不再 trim 后提交。
移除添加表单中的 tag/expand_nl；「追加自然语言」复用 nl 表单；变体编辑、逐字段标记与图片上传继续工作。

### 7.3 自动补齐、生成标记、字段锁

**决策**：有效 v5 条目只有必填 nl，没有可自动补齐的基础缺口；不得为已移除字段继续产生任务，也不自动生成 variants。
保留 auto_complete 存储/设置兼容，但前端隐藏开关并说明当前没有基础缺字段；离组不再发布自动补齐请求。
`POST /api/tasks {type:"prompt_completion",ref,base_revision,trigger,entry_ids?}` 保持兼容，返回 202 已完成空 TaskView；不调用 LLM、不改组 revision。
同 key 返回同空任务；仍校验目标/请求/CAS，412/409 语义不变；隐藏手动补全按钮，不将其偷换成重写 nl。
旧 completion/generation 冻结任务增加版本门禁：缺 content_schema_version 或 <5 的未完成任务置 paused，error_code=`prompt:schema_changed`。
恢复先核对已落库收据并补报告；禁止重放旧 LLM 调用或应用旧三字段结果；只有重新提交的新任务使用 v5 合同。
旧回调到达时先核对任务版本与归属，不能因 Entry.pending 已清空而新建锁或写回；终态旧报告可只读查看。
新 prompt_generation 请求路径与 brief/count/subject_mix 保持原合同；输出 schema 仅 nl、disable、可选 aspect（及原 index/组封装）。
variants 本期不由 LLM 自动生成；返回废弃字段属于非法响应，报告 entry:invalid，不通过旧导入适配器容错。
LLM 合同声明 NAI 输出；结果统一标准化后写入，generated.nl=true，variants={}；无效条目丢弃、count_short 沿用。
任务输入冻结 content_schema_version=5、normalization_version；保留每批≤20、幂等追加、CAS 有限重试与 fake LLM 测试边界。
用户提交 nl 即清 generated.nl、edit_versions.nl+1，同值也算编辑；variant 的增删改继续逐 key 更新标记/计数。
pending.nl 类型为将来兼容保留，本期无补齐缺口不产生新锁；不得借此增加变体生成能力。
最小测试：v1–v4→v5、三字段全非空/重复/部分空、长内容拒绝、备份失败、墓碑、高版本、重读幂等、variants/图片保持。
最小测试：旧 JSON/TXT/组包导入、新格式拒旧字段、人工同值清标记、旧任务暂停/迟到回调、离组零 LLM、generation 只写 nl。
