## 7. 变体等功能规格（用户已裁决）

本期实现（已完成，详见 F30 文档；其中 tag / expand_nl 与「默认 / 纯自然语言」视图、补全字段的描述已被 F31 取代，见 §5.3）：
1. 数据：`Entry.variants: {key: string}`，每个 key 对应单个多行文本，默认空；需 schema_version 升级迁移、导入导出（TXT 转义换行）、编辑 API。
2. UI：字典标题的 nsfw 标识移到标题文本右侧，标题下显示总条数；右侧按钮区为视图分段切换「默认 / 纯自然语言 / 变体」。默认=现卡片（tag+expand_nl）；纯 NL=只显示 nl；变体=左侧窄 key 列表 + 右侧多行编辑，列表下加号添加 key（空白内容）；「请求生成」按钮先占位。
3. 自动补齐：组级开关（新建取首选项默认，默认开；导入/复制继承源；用户可改），首选项可配默认值；切换到其他组或离开提示词页时，对缺失的 tag/expand_nl/nl 发布 prompt_completion 任务。
4. 生成锁定：在途字段标记为 pending，下次自动请求排除，防止反复进出重复提交；结果返回时若用户已在该字段填了非空内容，丢弃生成以用户为准。
5. 生成标记：模型生成的文本字段级标记，前端文本框有区别表现（不能只靠颜色）；用户任何改动清除标记；导入源不强制带标记；prompt_generation 新条目也标记。

只写计划，不实现：
- 词典处理列表的变体批量生成（配置 key、选 skill、覆盖开关默认否；skill 库分页按分类上传，含「提示词/变体生成」组和创建指导 skill）。
- 变体引用：生成提交时可配置变体 key 查找顺序，末位必须是默认项（tags / tag+exp_nl / full_nl 三选一），全部未命中弹警告。
- 变体自动追加（批量生成时选框默认开，首选项可改；记录 key→skill，离开界面时对 key 不存在或全空白的条目自动填充）。
- 变体 key 的「请求生成」。

已取消：
- 阅读/编辑模式（默认阅读、编辑模式聚焦清标记、阅读模式悬停 + 快捷键 c 清标记）：已取消（用户 2026-10-20 决定，必要性不足，尚未实现）。生成标记清除规则维持现有行为：任何用户编辑即清除。
