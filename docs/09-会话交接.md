## 3. 环境坑

- PowerShell 拦 npm.ps1 → 用 `npm.cmd`；ps1 脚本须 `powershell -NoProfile -ExecutionPolicy Bypass -File`。
- PowerShell 把 git push 进度判成 stderr，看着像报错实际成功。
- 停服务要 `taskkill /T` 杀进程树。
- rg 不在 PATH，用 grep 工具。
- LLM 网关（api.sourcesdata.com）拒绝 Python urllib 默认 User-Agent（返回 502）；`llm/adapters.py` 已统一加 `StyleLoraAutom/0.1.0`。临时脚本直连时也要设 UA。
- 6 个非 claude 模型的图像输入能力尚未有效测试（之前的 502 是 UA 导致）；claude-opus-5-5 / claude-sonnet-5-5 已确认支持图像。
- 密钥在用户全局 opencode 配置里，不得回显；NAI MCP token 需用户临时提供。
- 临时目录 `C:\Users\ADMINI~1\AppData\Local\Temp\opencode`；`devcache/` 已 gitignore，用完即删。
- 当前遗留：临时目录 `luna_gen.py`、`devcache/luna-test/`，用户确认不需要后删除。
