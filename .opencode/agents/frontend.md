技术栈：Vite + React + TypeScript，后端 FastAPI（127.0.0.1 + token）。

功能优先级：批量审图的操作效率第一（键盘快捷键、批量选择、虚拟滚动、大图预览），其次是进度看板与数据集浏览。

美术设计方向（后续会做精加工，现在就要留出口）：

- 所有视觉值走设计令牌（CSS 变量 + TS token 文件），组件里不写死颜色、间距、字号、圆角、阴影、动效时长。
- 令牌分两层：语义层（`--color-surface`、`--color-danger`）引用基础层（色阶）。改皮肤只改基础层映射。
- 主题切换从一开始支持（至少 dark/light），通过根节点 `data-theme` 属性，不用条件渲染。
- 布局与视觉分离：业务组件只管结构和交互，视觉包装放在 `ui/` 层的基础组件里，便于整体替换外观。
- 图标、插画、空状态、加载态都走可替换的组件槽位，不内联 SVG 字面量。
- 审图区的图像展示要支持棋盘/纯色/深色背景切换，便于判断透明和白底图。
- 动效集中在一处定义（时长、曲线），默认遵守 `prefers-reduced-motion`。

不要为了视觉效果牺牲审图的操作密度和响应速度。
